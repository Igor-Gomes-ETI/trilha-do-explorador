# ✂️ Trilha do Explorador — Print & Play

Esta pasta reúne o material **Print & Play** do Trilha do Explorador, preparado para impressão em folhas A4.

## Pacote principal

O pacote `Trilha-do-Explorador-Print-and-Play.pdf` reúne os materiais prontos para impressão, incluindo mapas das modalidades, materiais de jogo, peças recortáveis e mapa em branco.

### Impressão sugerida

- Papel: A4
- Escala: 100% / tamanho real
- Para peças recortáveis, papel de maior gramatura ou colagem em papel cartão pode aumentar a durabilidade.
