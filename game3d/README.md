# Trilha do Explorador 3D

Protótipo experimental 3D do **Trilha do Explorador**, executado diretamente no navegador com Babylon.js/WebGL.

Esta versão é desenvolvida separadamente do jogo digital 2D para preservar a versão estável enquanto o novo visual evolui.

## Controles
- Arraste para girar a câmera.
- Scroll para aproximar/afastar.
- Role o D12.
- Clique em uma casa vizinha para mover o explorador.

## Estado
Alpha 0.1: terreno 3D, câmera orbital/isométrica, iluminação, névoa, rio, vegetação procedural, Base, Marco, personagem 3D, D12 e HUD inicial.
